#📚 Digital Library – Frontend

A simple and clean frontend interface for a Digital Library built with HTML, CSS, and JavaScript.
It includes book search, sorting, and pagination, with data loaded from a local books.json file.


---

🚀 Features

Dynamic book catalog table

Search by title, author, or category

Column sorting (ascending/descending)

Pagination (5 books per page)

Modern UI with Brown / Off-white / Burgundy color theme



---

📁 Project Structure

index.html
books.json
README.md


---

▶️ How to Run

1. Make sure all project files are in the same folder


2. Open:

index.html


3. Ensure:

books.json

is in the same directory so the fetch() request works correctly.
